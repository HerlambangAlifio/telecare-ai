# TeleCare AI — prototipe Flutter

Empat halaman: Beranda, Form Keluhan, Hasil Asisten AI (aturan offline), Chat Dokter (simulasi offline).

## Menjalankan
1. Buka folder `telecare_aplikasi` di VS Code.
2. Terminal: `flutter pub get`
3. Hubungkan HP Android (USB debugging) atau buka emulator.
4. Terminal: `flutter devices` lalu `flutter run`.
5. APK: `flutter build apk --debug`.

Semua fitur berjalan tanpa server. Sistem rekomendasi hanya rule-based dan bukan AI generatif, diagnosis, atau layanan dokter aktif. Tidak cocok digunakan untuk keputusan medis nyata.
